COBOL SALES-REPORT PRIMER
=========================

KEY KEYWORDS & CONCEPTS
------------------------
PERFORM       - Calls/loops over a paragraph
EVALUATE TRUE - COBOL's switch/case statement
88-level       - Condition name (boolean flag on a field)
PIC / PICTURE  - Defines a field's type and size (X=alpha, 9=numeric, V=decimal, Z=zero-suppress)
WORKING-STORAGE - Memory declared for intermediate/temporary variables
FD             - File Descriptor; defines the layout of a file record
READ ... AT END - Reads next file record; sets flag when exhausted
COMPUTE        - Evaluates an arithmetic expression
MOVE           - Assigns a value to a field
WRITE ... FROM - Outputs a record/line to a file

--------------------------

WHAT THE PROGRAM DOES
--------------------------
SALES-REPORT reads a flat-file of sales transactions (sales.dat), where each record
holds a salesperson ID, a two-character region code, and a dollar amount. As it loops
through every record it accumulates a running total, a record count, and tracks the
single highest sale and the salesperson responsible for it. Each record is also
classified into one of four tiers — BRONZE, SILVER, GOLD, or PLATINUM — based on the
sale amount, and a formatted detail line is written to report.txt.

After all records are processed, a summary section is appended to the report showing
the total number of records, the grand total of all sales, the average sale value, and
the top single sale with the corresponding salesperson ID. File handling follows the
classic COBOL open-process-close pattern, with an 88-level EOF flag driving the main
read loop.
